Agende em quatro passos

O assistente conduz a conversa do começo ao fim. Você só responde ao que for perguntado.

  1. Escolha o serviço

    Consulta médica, odontológica ou de enfermagem.

  2. Identifique-se

    Informe os dados pedidos para registrar o atendimento.

  3. Selecione o horário

    Só aparecem horários livres, então ninguém marca em cima do outro.

  4. Confirme

    Revise as informações e finalize. A solicitação segue para a equipe.

Uma agenda organizada para quem atende

As solicitações ficam registradas em um banco de dados online. Os profissionais acompanham cada pedido e atualizam o andamento.

Como foi construído

Interface
React 19 e TypeScript, com mapa em Leaflet.
API
FastAPI (REST): processa as mensagens, aplica as regras e consulta a agenda.
Dados
Banco online com serviços, equipe e ocupação de horários.
Conversa
Fluxos pré-definidos, simples e previsíveis.
Canal
Web e integração com WhatsApp.
